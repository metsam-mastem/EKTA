## Use rules
1. Select only artifacts needed for the risk and scale of the collaboration.
2. Assign owner, version, status, approval authority, and review date.
3. Link decisions, requirements, deliverables, and evidence using stable identifiers.
4. Separate informal working agreements from legally binding contracts.
5. Legal, privacy, employment, IP, and regulatory documents require jurisdiction-specific qualified review.
6. Record changes; never silently replace an approved agreement.
