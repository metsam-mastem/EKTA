## Adoption checklist
- [ ] Confirm canonical upstream.
- [ ] Inspect license and notices.
- [ ] Check release and maintenance activity.
- [ ] Review security advisories and dependency risk.
- [ ] Inspect architecture and extension points.
- [ ] Test on target OS/hardware.
- [ ] Compare alternatives.
- [ ] Record adoption in an ADR.
- [ ] Pin version/commit for reproducible examples.

Do not copy code merely to accelerate development. Prefer links, adapters, small examples, and license-compliant reuse.
