## قراردادهای مهم

- مخزن Git منبع اصلی و قابل بازیابی پروژه است.
- کاوشگر نسخه 0.2 خواندنی است؛ Workspace 0.4 امکان Import staging و Draft محلی دارد، اما canonical را مستقیماً تغییر نمی‌دهد.
- جست‌وجو واژگانی و قطعی است، نه معنایی.
- فقط مسیرهای تعریف‌شده در کد ایندکس می‌شوند؛ کل دیسک اسکن نمی‌شود.
- مجوز مخزن هنوز تعیین نشده است؛ عمومی بودن مخزن به معنی مجوز بازاستفاده نیست.
- قابلیت‌های Roadmap را قابلیت موجود تلقی نکنید.

## نگهداری مستندات

نسخه محصول و نسخه مستندات مستقل‌اند. هر انتشار باید CHANGELOG، فهرست مستندات، راهنمای نصب/کاربری در صورت تغییر رفتار، Context Continuity و آزمون‌های مرتبط را به‌روز کند.

اگر رفتار نسخه نصب‌شده با این راهنما متفاوت است، ابتدا Commit یا نسخه نصب‌شده را مشخص و مستندات همان نسخه را بررسی کنید.
