# EKTA Roadmap

Planning status: proposed; priorities may change after maintainer review.

## Phase 0 — Foundation
- [x] Establish repository identity.
- [x] Create initial charter, governance, architecture, taxonomy, schemas, and templates.
- [x] Define continuity and evidence rules.
- [ ] Approve charter and select license.
- [ ] Review initial taxonomy and repository structure.

## Phase 1 — Taxonomy and encyclopedia
- [ ] Populate domain, layer, and type registries.
- [ ] Create canonical concept ID registry.
- [ ] Add cross-layer concepts: runtime, engine, scheduler, controller, manager, executor, worker, driver, adapter, interface, bus, broker, gateway, queue, cache, state machine, pipeline, monitor, supervisor.
- [ ] Add software engineering and computer architecture foundations.
- [ ] Add electronics, embedded, and systems engineering foundations.
- [ ] Add relationship maps.

## Phase 2 — Evidence corpus
- [ ] Curate official standards and specifications.
- [ ] Add Nature portfolio and peer-reviewed research records.
- [ ] Curate GitHub/GitLab implementations.
- [ ] Add source assessments and version snapshots.
- [ ] Trace claims to sources.

## Phase 3 — Practice library
- [ ] Architecture discovery and repository audit playbooks.
- [ ] Concept research and prototype design playbooks.
- [ ] Testing, validation, and release checklists.
- [ ] Decision matrices and worked examples.

## Phase 4 — Automation
- [ ] Validate schemas, IDs, tags, links, and edges.
- [ ] Generate JSON/JSON-LD and graph edge lists.
- [ ] Generate visual maps.
- [ ] Add CI and link validation.
- [ ] Add local search and static site.

## Phase 5 — Interactive atlas
- [ ] Faceted search and navigation.
- [ ] Interactive graph and cross-layer explorer.
- [ ] Concept comparison and decision lab.
- [ ] Learning paths and practical labs.
- [ ] AI retrieval/context export with provenance.

A phase is not complete because a checklist exists. Each item requires an artifact, review, and evidence.
