# EKTA Roadmap

Planning status: active; priorities are governed by the approved charter, current implementation plan, and evidence from each release candidate.

## Phase 0 — Foundation
- [x] Establish repository identity and charter.
- [x] Create governance, architecture, continuity, taxonomy, schemas, and templates.
- [x] Approve project charter and product vision (2026-11-23).
- [x] Add Python runtime, API, CLI, initial explorer, validator, graph exporter, and CI.
- [ ] Select repository and content licensing policy.

## Phase 1 — Taxonomy and encyclopedia
- [x] Publish 26 top-level engineering territories.
- [x] Maintain operational domain, layer, knowledge-type, and relation registries.
- [x] Add concept JSON Schema and taxonomy validation.
- [ ] Extend schemas to source, technique, architecture, decision, workflow, and implementation records.
- [ ] Establish a machine-readable canonical ID registry.
- [ ] Standardize relationship front matter around stable target IDs.
- [ ] Expand concept corpus across all 26 territories with evidence-backed records.

## Phase 2 — Evidence corpus
- [ ] Curate official standards and specifications.
- [ ] Add peer-reviewed research records and literature maps.
- [ ] Curate GitHub/GitLab implementations with license and maintenance assessment.
- [ ] Add source versions, access dates, source assessment, and stale-source indicators.
- [ ] Trace material claims to exact sources.

## Phase 3 — Practice library
- [x] Establish knowledge intake playbook and work-item template.
- [ ] Add architecture discovery and repository audit playbooks.
- [ ] Add concept research and prototype design playbooks.
- [ ] Add testing, validation, and release checklists.
- [ ] Add decision matrices and worked examples.

## Phase 4 — Automation
- [x] Validate concept schema, duplicate IDs, taxonomy references, territory mappings, and local Markdown links.
- [x] Generate typed graph export and expose unresolved edges.
- [x] Add GitHub Actions CI for documentation, runtime, tests, frontend syntax, and graph export.
- [x] Add deterministic lexical search, hashtag and field selectors, snippets, ranking, and facets.
- [ ] Enforce canonical relationship target resolution and edge integrity gates.
- [ ] Add JSON/JSON-LD and visual graph export.

## Phase 5 — Interactive atlas
- [x] Add responsive Persian RTL browser explorer.
- [x] Add unified search, territory/domain/layer/type/status filters, and hashtag chips.
- [x] Add concept/document detail views with content, relationships, and metadata.
- [ ] Add interactive graph canvas and neighborhood traversal.
- [ ] Add concept comparison and Decision Lab.
- [ ] Add learning paths and practical labs.
- [ ] Add source evidence panels and richer Persian/English synonym search.

A phase is not complete because a checklist exists. Each item requires an artifact, review, and inspectable evidence. The current v0.2 explorer is an initial implementation slice, not a complete v1.0 release.
