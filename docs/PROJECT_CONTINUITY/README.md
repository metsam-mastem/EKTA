# Project Continuity

This directory contains durable project context intended to make EKTA resumable without any ChatGPT conversation, model memory or temporary agent session.

- [Conversation context archive](CHAT_SESSION_ARCHIVE_2026-11-24.md) — decisions, project facts, work history and open tasks captured from the current work session.
- [Agent onboarding](AGENT_ONBOARDING.md) — how a new human or AI contributor must inspect, implement, test and hand off work.
- [Recovery runbook](RECOVERY_RUNBOOK.md) — clean clone, restore and chat-deletion procedure.
- [Continuity manifest](CONTINUITY_MANIFEST.yml) — machine-readable entry points, constraints and verification state.
- [Orchestration plan](ORCHESTRATION_PLAN.md) — dependency-aware work packages, parallel tracks and delivery gates.

The archive is a structured summary, not a verbatim transcript. Git history and approved project artifacts remain authoritative. Always refresh live branch, PR and CI status before resuming.
