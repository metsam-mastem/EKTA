# Glossary and Terminology Policy

Keep canonical technical terms in English when established in standards, source code, or engineering practice. Add Persian equivalents, transliterations, and explanatory notes as aliases. Do not translate identifiers, APIs, protocol names, or standard designations.

Each entry should include canonical term, definition, domain, layer, knowledge type, aliases, disambiguation, related concepts, and sources.

Aliases point to one canonical record only when meanings are equivalent. If meanings differ materially, create separate records. Expand acronyms on first use and record collisions.

Stable IDs are immutable and never recycled.
