# VES User Guide — Initial Prototype

1. Open web/index.html in a modern browser.
2. Review the sample Architecture Board.
3. Select a card to inspect type, name, status and properties.
4. Edit fields in Inspector and choose Save changes.
5. Add an entity from Card Library or use Add entity.
6. Drag cards to reposition them.
7. Run validation to check relationship endpoints.
8. Export JSON to download the current project representation.
9. Reset demo restores the sample model after confirmation.

This prototype is an interaction demonstration, not a production engineering validator. Browser validation currently checks dangling relationship endpoints only; Python core provides additional deterministic checks.
